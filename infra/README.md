# Инфраструктура

- `servers.json` — каталог серверов для клиента. Персональных данных нет, отдаётся
  статичным файлом за nginx или CDN. Хосты пока заглушки `example.com`.
- `ru-1/`, `us-1/` — конфиги и деплой каждого сервера (появятся на этапе 2).
  RU — российский дата-центр, US — OVH. Общей базы нет.
- Пароли и ключи в git не кладём: только через переменные окружения на сервере.
